Offline build for this checkout
===============================

The Gradle wrapper in this repository needs network access and is not usable here.

The sources can be compiled offline with javac:

    /opt/fm/build.sh [output-dir]        # default output: /tmp/fm-classes

It uses the dependency jars in /opt/fm/deps and the JavaCC-generated parser in
/opt/fm/gen, which was generated from this checkout's grammar by the project's
own build rules. javac and java are on PATH.

To run a small program against the compiled classes:

    javac -cp "/opt/fm/deps/*:/tmp/fm-classes" -d /tmp/scratch MyProbe.java
    java -cp "/opt/fm/deps/*:/tmp/fm-classes:/tmp/scratch" MyProbe

JUnit 4 and the JUnit console launcher are in /opt/fm/deps if you want to run a
throwaway test of your own.
