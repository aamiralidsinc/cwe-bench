# A secret header on our JSON alert was delivered to another host after a redirect

## What we observed

We send operational alerts through the JSON notification target. The address carries an extra header:

`json://alerts.internal.example/hook?+X-Api-Key=s3cr3t`

The gateway in front of that hook answered 307 and named a host we do not operate. The notification was repeated there. The client library drops only the standard authorization header when the host changes, so a header we added ourselves travelled with the replay.

## Impact

Whoever can make that endpoint answer with a redirect receives the header and the message.

## What must keep working

- Operators need a per-target yes/no switch named redirect, written the same way as the existing certificate-checking switch. With redirect=no, the host named by a redirect must not be contacted, and a redirect response must not count as a successful delivery or as retrieved content. With redirect=yes, or with the switch left off the address, behaviour stays as it is today: redirects are still followed. A move to another path on the same server must still complete when the switch is not turned off.
- The same switch must be honoured when it is written beside the target in a configuration entry, the way the certificate-checking switch already can be.
- Custom headers must still reach the host we configured, including when the switch is off and that host answers with success.
- Turning a target back into an address and loading that address again must keep a switch we set, and must not invent parameters we did not set. The certificate-checking switch must keep its current meaning on targets that set it and on targets that do not.
- Fetching a remote file to attach to a message, and loading a configuration document from a remote address, must keep working when the server answers normally, and must still follow a redirect to another path on that same server when the switch is left unset.
- The details a caller already receives for a target that did not set this switch must stay as they are today.
