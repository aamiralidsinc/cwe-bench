## Step 2: how the incomplete pairs were recovered

1. **Repo.** Resolved from the GitHub global advisory (`source_code_location`, references) and the github.com references of both advisories.
2. **Evidence for the missing fix**, gathered for each pair:
   1. commit URLs and **merged PRs** (`merge_commit_sha`) in the advisory and API references;
   2. **`git log --all --grep`** for every id and alias (GHSA, CVE, PYSEC…) in the blobless clones on the VM (`~/.tb-graders/cwe/stacking/clones`; missing ones were cloned);
   3. where neither found anything, the **tag range** (previous release .. fixed release), checked for subjects that match the advisory.
3. **Commit choice.** Each candidate was checked by hand. Rejected: release, doc and changelog commits; commits that fix the *other* advisory of the pair; feature commits.
4. **Labels.** SZZ labels came from the unchanged `szz_pairs.py` (its output folder pointed at `/tmp`).
5. **Not recovered:** the remaining 91 pairs. Typical reasons:
   - only doc or history commits name the id (james, rubygems, phpmailer);
   - the tag range is too wide to pick one commit (struts, zf1, cxf, activemq);
   - only one side was found (opentsdb, kylin, shopper, jquery-rails, devise-two-factor, oneuptime, pheditor);
   - the pair resolves to the same commit (jinja2).
6. **Dropped:** vm2 GHSA-hw58 (host-process abort, CWE-248), as DoS in effect.
