## Known hazard: concurrent gates/trials prune Docker networks
`gate.py` runs `docker network prune -f` to free Docker's ~31 network pools (kept trial containers
leave networks behind). With many gates/trials in parallel this can kill a *live* neighbour's
network (it killed trestle's first gate; it passed on re-run). The code treats network/API cuts as
**retryable, never a failure**, so it self-heals, but keep concurrency sane (your ≤16 trial runs is
fine; avoid running 12 full gates at the exact same moment).
